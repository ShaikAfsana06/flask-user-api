# Flask User API

## Description
A simple REST API for managing users using Python and Flask. Supports GET, POST, PUT, and DELETE operations.

## Features
- Create a new user (POST)
- Get all users (GET)
- Get a single user by ID (GET)
- Update a user (PUT)
- Delete a user (DELETE)

## Tools & Technologies
- Python
- Flask
- Postman or curl for testing
